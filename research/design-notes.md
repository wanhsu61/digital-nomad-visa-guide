# 设计与迭代记录

## 起点

项目从一个 Gemini 生成的网页雏形开始（见 `gemini-prototype/`）：复古报纸风格，15 个国家，手绘示意地图，数据部分已过时（例如葡萄牙入籍年限、泰国 DTV 新规）。

## 目标

帮助想申请数字游民签证的中国人：看清签证分布在哪些地区，挑出适合自己的国家，并知道怎么一步步准备。

## 主要设计决定

| 决定 | 原因 |
|---|---|
| 真实国界世界地图，按收入门槛三档着色 | 一眼看出分布和难度；使用 Natural Earth 数据预投影，不依赖运行时地图库 |
| 首屏同时放简介、签证好处、关键数字、地图和 22 国速查 | 打开页面就能获得最多信息，减少滚动 |
| 国旗卡片 + 大号签证缩写（DTV、D8…） | 好辨识、有冲击力；国旗半透明，保证文字清晰 |
| 国家档案顶部放迷你世界地图并标红 | 参照谷歌搜索城市的呈现方式，快速定位所在大洲 |
| 全站金额换算为人民币约数 | 目标读者是中国人；保留官方原币金额，避免递交时出错 |
| "中国护照申请人"单独成段，另列不对中国开放的项目 | 避免读者在走不通的通道上浪费时间 |
| 数据集中在 countries.js，README 由脚本生成 | 网页和文档始终一致，新增国家或申请方法只改一处 |
| 国旗使用 flagcdn.com | 标准、准确，替代最初手绘的简化国旗 |
| 系统字体优先 | 国内访问 Google Fonts 不稳定，中文使用系统字体栈 |

## 迭代过程

1. 重构信息架构：地图、国家简介、签证优势、达成条件、申请方法、申请费用、官方入口，全部数据重新核对到 2026 年 10 月。
2. 卡片改为全幅国旗背景，标注所在洲；整体改为浅色主题；国家档案增加定位地图。
3. 首屏去掉收入输入框，改为"数字游民"大标题、介绍、签证好处与配图；地图着色改为按门槛分级。
4. 国旗改用 flagcdn.com。
5. 提高信息密度：首屏三栏 + 地图与速查榜并排，整体字号和间距收紧。
6. 速查榜改为小国旗 + 中英文国名 + 门槛；卡片国旗降低不透明度，加入大号签证缩写。
7. 汇率更新为 2026-09-30 中间价，全站金额改为人民币约数。
8. 国家档案的定位地图改为完整迷你世界地图，目标国家标红并加脉冲圆圈。

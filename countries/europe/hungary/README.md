## 一览

| 项目 | 内容 |
|---|---|
| 签证名称 | 白卡（White Card） |
| 所在洲 | 欧洲 |
| 资金门槛 | 约 ¥2.3 万 / 月（税后）（原文：约 €3,000 / 月（税后）） |
| 家属 | 不允许家属随行，每人需单独申请 |
| 有效期 | 1 年，可续 1 年（最长 2 年） |
| 审批时间 | 约 4 周 |
| 政府费用 | 约 ¥840 |
| 标签 | 畅行申根 |

## 国家简介

布达佩斯物价在申根国家中偏低，交通便利，适合单身远程工作者在中欧落脚。

## 签证优势

- 审批快，约 2–4 周
- 生活成本在申根区里较低
- 可在境内或境外递交

## 需要注意

- 不允许家庭团聚
- 最长只有 2 年
- 不能接匈牙利本地客户

## 达成条件

- 税后月收入约 ¥2.3 万（原文：税后月收入约 €3,000）
- 为境外雇主或客户工作
- 医疗保险
- 住宿证明、无犯罪记录

## 中国护照申请人

通过 Enter Hungary 系统在线填表，向驻华使领馆递交原件。

## 申请方法

1. **Enter Hungary 在线填表**：注册账户并填写白卡申请。
2. **使领馆递交**：携带原件及生物信息到驻华使领馆。
3. **入境领卡**：入境后到移民局领取居留卡。

## 申请费用

| 项目 | 约合人民币 | 原文 |
|---|---|---|
| 申请费 | 约 ¥460–840 | 约 €60–110 |
| 医疗保险 | 约 ¥2,000–4,000 / 年 | 约 ¥2,000–4,000 / 年 |

> 另建议预留：文件公证、认证、翻译 ¥1,000–3,000，医疗保险 ¥1,500–6,000/年，首月住宿押金与机票。

| 项目 | 内容 |
|---|---|
| 签证名称 | 远程工作签证（RWV） |
| 所在洲 | 非洲 |
| 资金门槛 | 年入 约 ¥26.7 万（原文：年入 ZAR 650,796） |
| 家属 | 家属可随行 |
| 有效期 | 最长 3 年 |
| 审批时间 | 约 8 周 |
| 政府费用 | 约 ¥170 |
| 标签 | 携带家属 |

## 国家简介

开普敦是南半球的游民之都，自然风光一流，与欧洲时差小。

## 签证优势

- 最长 3 年
- 政府费用低
- 与欧洲时区接近

## 需要注意

- 中国护照需签证，经 VFS 递交
- 不通向永居
- 治安需谨慎选择居住区

## 达成条件

- 年收入 ≥ 约 ¥26.7 万（原文：年收入 ≥ ZAR 650,796）
- 境外雇主或客户
- 医疗保险
- 无犯罪记录证明

## 中国护照申请人

向南非驻华使领馆或指定签证中心递交。

## 申请方法

1. **准备文件**：收入证明、合同、无犯罪证明、保险。
2. **签证中心递交**：按领区预约。
3. **入境**：每满 183 天须关注南非税务登记要求。

## 申请费用

| 项目 | 约合人民币 | 原文 |
|---|---|---|
| 政府费用 | 约 ¥170 | ZAR 425 |
| 签证中心服务费 | 按 VFS 当地标准 | 按 VFS 当地标准 |

> 另建议预留：文件公证、认证、翻译 ¥1,000–3,000，医疗保险 ¥1,500–6,000/年，首月住宿押金与机票。
